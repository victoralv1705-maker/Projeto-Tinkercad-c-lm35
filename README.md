# 🌡️ Sistema de Acesso por Temperatura

Projeto de um sistema de controle de acesso por temperatura desenvolvido no Tinkercad utilizando Arduino.

## 🔧 Componentes utilizados

- Arduino Uno
- Sensor de temperatura LM35
- Display LCD 16x2
- LED verde
- LED amarelo
- LED vermelho
- Buzzer

## 💻 Funcionamento

O sensor LM35 realiza a leitura da temperatura.

De acordo com a temperatura identificada, o sistema altera o estado dos LEDs, exibe informações no display LCD e pode acionar o buzzer.

O projeto foi desenvolvido para praticar a utilização de sensores, LEDs, display LCD e estruturas condicionais na programação do Arduino.
